# AmaBhaina · ଆମ ଭାଇନା

Odisha-first pandit discovery and booking marketplace for Bhubaneswar, Cuttack and Puri.

## Project boundaries
Only this repository and dedicated AmaBhaina infrastructure are in scope. Never change unrelated repositories, deployments, DNS, databases or credentials.

## Initial scope
Responsive marketplace, sample listings, search and filters, profile details and simulated booking requests. No real payments or live bookings in the prototype.

Brand direction: ॐ Bhaina — Your Puja. Our Bhaina.
